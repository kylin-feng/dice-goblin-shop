## 一、收款：PayPal 开通（约 30 分钟，0 费用）

静态站没有后端，所以收款用 **PayPal 官方纯前端结账按钮**（免月费，只在成交时扣费）。开通前商店显示"预留订单"兜底，不影响浏览。

1. **注册 PayPal 中国账户**：www.paypal.com/c2 → 个人账户即可收款（身份证 + 手机号 + 一张国内银行卡）。跨境收款个人账户够用。
2. **创建 Live 应用拿 Client ID**：
   - 打开 developer.paypal.com → 登录 → My Apps & Credentials → 切到 **Live** 标签 → Create App（名字随意，如 dicegoblin）
   - 复制 **Client ID**（一串字母数字，不是 Secret）
3. **填入商店配置**：编辑 `assets/js/shop-config.js`：
   ```js
   PAYPAL_CLIENT_ID: "你的ClientID",
   PAYPAL_ME: "你的PayPalMe用户名",   // paypal.me/后面那截，作为兜底付款链接
   CONTACT_EMAIL: "你的接单邮箱",
   ```
   然后 git push（或按第四节的 gh api 方式上传 3 个文件：shop-config.js + index.html + products/ 三个页面）。
4. **验证**：打开任一产品页，绿色 Secure checkout 区出现黄色 PayPal 按钮即成功。
5. **费率（真实数字）**：跨境商品交易 **4.4% + $0.30/笔**；提现走 Payoneer/连连/万里汇约 **1.2%**（$35 电汇到国内银行不划算，小额别用）。

> 客户付款 → PayPal 邮件通知你 → 你按第三节发货 → 单号在 PayPal 后台填到订单上。退款在 PayPal 后台一键处理。

- 筛选**义乌发货**的店铺；多数支持一件代发（可先拿 3-5 套样品验货再批量）。

- **实拍图替换**：拿样品在窗边自然光下拍 5-8 张（俯拍+斜 45°+手持），替换 `assets/img/` 下同名 SVG 文件（SVG 先留着做备份，文件名保持一致）。真实实拍图转化率远高于渲染图，**有实拍图后尽快替换**。

## 三、物流：国际发货 SOP（每单约 ¥25–35，7–15 天到美国）

**渠道二选一：**

- **零注册起步**：淘宝搜「国际小包代发 美国专线」，下单代发（把打包好的件送/寄给代发点，或让对方上门取）——每单贵 5 元左右，不用注册账号，首月推荐。
- **自注册（量起来后）**：燕文物流 yanwen.com / 4PX / 云途，注册卖家账号（个人可），在线打面单，每日揽收或送网点。

**发货流程（每单 10 分钟）：**
1. PayPal 收到付款邮件 → 核对收件地址（美国地址注意 Apt/Suite 单元号）
2. 气泡膜包裹骰子（金属套重点包角）+ 小感谢卡（可选，手写一行 "Roll well, adventurer!" 复购率神器）
3. 打面单（渠道后台或代发点）→ 贴单 → 交寄
4. **把运单号填回 PayPal 订单**（后台 → 订单 → Add tracking）+ 给买家发邮件："Your Dice Goblin order has shipped! Track: <单号链接>"
5. 本地记账：日期 / SKU / 卖家名 / 运单号 / 收款 $ / 成本 ¥

**申报**：面单如实写 "polyester dice set"，申报价值 $10-15（低值小包美国免税线内）。
